每章新增依据教材目录与正文整理的知识点，九章共 63 个知识点条目，标明教材小节与印刷页码，说明概念、公式条件、解题方法、易错点，并链接相关习题。第八章也有独立整理。在线目录可进入“知识点整理与学习路线”，每题上方及推导末尾可返回本章知识点，复习后可一键返回原题，保留展开步骤与阅读位置；刷新可恢复本题阅读状态。

每题包含：题目条件与教材联系、解题思路、关键步骤与完整推导、方法复盘、独立自检、单独标明的最终答案。自检参考集中放在各章末尾；阅读不需要另外对照编者解析书。
