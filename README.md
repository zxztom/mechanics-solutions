## 阅读方法

先点章节，再在顶部输入这一章的题号即可跳转；题目链接也可直接分享，例如 `#2-13`。题后“查看自检参考”可以跳到章末，并有返回原题的链接。支持全文搜索、整章连读、字号调整和记忆阅读位置。

离线使用请下载 HTML，双击用较新的浏览器打开。公式、字体和配图均已内置。Markdown 保留可编辑的数学源文与图示说明，完整配图请看 HTML 或 PDF。
