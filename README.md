# 舒幼生《力学（物理类）（第二版）》习题详解

这是一份配合 **舒幼生《力学（物理类）（第二版）》** 使用的课后习题学习讲义，共 **349 题**，内容从质点运动学到狭义相对论。

对应教材：舒幼生《力学（物理类）（第二版）》。另以舒幼生《力学习题与解答（物理类）（第二版）》作为参考解答资料。

本讲义由学生在学习过程中借助 AI 辅助整理，着重补充思路说明、完整推导、教材理论的联系与明确标出的最终答案，便于配合原教材学习；这是学习整理版，不是教材编者出版的官方解答书。
